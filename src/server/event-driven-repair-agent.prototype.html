What happens after the tenant sends a text?

Fix This saves the text in the repair case. The text wakes the repair agent. The repair agent can ask the tenant for information and prepare a contractor proposal. It must stop for approval from the property manager. It can book only after the tenant gives access authorization, the property manager gives approval, and the contractor confirms the visit.

This page checks one safety rule: the same work must not happen twice when a text provider retries a message, the tenant sends more information, the repair agent fails, or the server stops.

Test data only — this page sends no real text and makes no real call

The rule

One saved message wakes one repair-agent run. Before Fix This sends a text or makes a call, it saves one record for that action. If it does not know whether the provider completed the action, it checks the provider before it tries again.
